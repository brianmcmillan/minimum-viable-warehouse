# Mutation run

Generated by `make mutate` (`tests/run_mutations.sh`). Do not edit by hand.

Each mutation is one file in `v3_*/tests/mutations/`. The harness applies it to a
scratch copy of the model, runs that model's `tests/run_tests.sh`, and records
KILLED when at least one assertion fails (or the suite aborts) and SURVIVED when
the suite stays green. The working tree is never patched.
`shared` mutations break the plumbing every model shares: the delete rule, the
archive, load control and dedup. `model` mutations break something only that
model has. Broken assertions are core ids (`tests/core_spec.tsv`) or MODEL
labels, prefixed with the MODEL section they print under.
